Move Turf.js geospatial math over DB data into PostGIS SQL (PGlite already runs full PostGIS 3.6.2 in-browser). No schema changes needed — all edits are query code. This fixes the two hot paths (marker drop, observation form) plus two latent bugs where code reads raw `geometry` (hex EWKB strings) as GeoJSON, silently breaking zoom-to-layer for own tables and the assignment-lines layers.

## Key technical constraint

All geometry columns are `geometry(GeometryCollection, 4326)` — and PostGIS **geography does not support GeometryCollections**. So distance queries must unnest members first:

```sql
SELECT min(ST_Distance(
  ST_SetSRID(ST_MakePoint($1, $2), 4326)::geography,
  ST_GeometryN(p.geometry, n)::geography)) AS distance_m
FROM generate_series(1, ST_NumGeometries(p.geometry)) AS n
```

Point/LineString/Polygon members are all geography-safe. `ST_Distance` returns meters on the spheroid (current code uses haversine km — same scale of accuracy) and returns 0 when the point lies inside a place, replacing the current buffer→convex→pointsWithinPolygon workaround dance. Only `ST_AsGeoJSON`/`ST_GeomFromGeoJSON` are used in the app today, but the extension bundle contains the full function set (ST_Distance/ST_DWithin/ST_Extent/ST_Envelope geography overloads verified in the shipped postgis--3.6.2.sql); the new test file proves this at runtime.

## Changes

- `nearestPlaces(db, { lng, lat, maxDistanceM, level: 'places1' | 'places2' | 'both' })` → `[{ place_id, label, distance_m }]`, ordered asc, `LIMIT 5`. ## Intentional behavior changes (all improvements)

1. Distances are true nearest-surface distances instead of distance-to-convex-hull-outline: identical for point places (all 32k apflora places), slightly smaller/more accurate for polygons; marginally more candidates can enter the 40-px threshold.
2. Containment is true containment — a point in a concave part of a polygon now counts as inside (before, only hull containment did).
3. Combobox: a place containing the observation shows "0 m" instead of distance-to-boundary.
4. Zoom-to-layer for own tables and assignment-lines layers start working (currently broken).
