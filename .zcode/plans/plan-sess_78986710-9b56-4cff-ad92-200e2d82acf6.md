# Dark mode with system-preset cycle toggle

## 1. State & theme application
- **`src/store.ts`**: add persisted setting following the `languageAtom` pattern:
  ```ts
  export type ThemeMode = 'system' | 'light' | 'dark'
  export const themeModeAtom = atomWithStorage<ThemeMode>(
    'themeMode', 'system', undefined, { getOnInit: true })
  ```
- **`src/App.tsx`**: read `themeModeAtom`; subscribe to `window.matchMedia('(prefers-color-scheme: dark)')` change events; compute `isDark = mode === 'dark' || (mode === 'system' && systemDark)`; effect sets `document.documentElement.dataset.theme = 'dark' | 'light'`; render `<FluentProvider theme={isDark ? darkTheme : lightTheme}>` (both themes already exist in `src/modules/theme.ts`).

## 2. Pre-paint boot shell (`index.html`) — no white flash
- Extend the existing head script: JSON-parse `localStorage.themeMode` (jotai stores `"system"` quoted), resolve via `matchMedia`, set `html.dataset.theme` + `html.style.colorScheme` before first paint.
- Add `html[data-theme='dark']` CSS variants for `#boot-splash` and `#boot-init` (dark gradient, light text, dark card/steps). The photo hero `#boot-home` stays as-is.

## 3. Global CSS (`src/style.css`)
- `html { color-scheme: light }` / `html[data-theme='dark'] { color-scheme: dark }` (native scrollbars/inputs adapt).
- Dark variants for: `.form-header` (+ `.filter`), `.form-container.filter`, `.list-view-header`, `.navs a` colors/hover, scrollbar colors, Uploadcare `--darkmode: 1`.
- Dark overrides for Leaflet chrome only (map tiles stay light per decision): popup content wrapper/tip, zoom bar buttons, attribution, draw toolbar.
- Fix `background-color: fff` typos in `.navs`/`.navs-resizable` → `transparent` (no visual change in light).

## 4. Cycle button in both headers
- New **`src/components/shared/ThemeChooser.tsx`** + module CSS, modeled on `LanguageChooser` (native button, white icon — headers are dark green in both layouts).
- Icon per mode: `MdBrightnessAuto` (system) / `MdLightMode` / `MdDarkMode`; click cycles **system → light → dark**; `title`/`aria-label` show the current mode (i18n).
- Insert next to `LanguageChooser` in `LayoutProtected/Header/Menu.tsx` (inside MenuBar) and `Layout/Header/Menu.tsx` (native button row).
- i18n: ids `themeModeSystem` / `themeModeLight` / `themeModeDark` with German `defaultMessage`s; add en/fr/it translations to `src/i18n/*.json`; refresh `extracted.json` via `npm run i18n:extract`.

## 5. Dark variants in component CSS
Pattern: `:global(html[data-theme='dark']) .someClass { … }` with dark greens/greys matching `darkTheme`. Files:
- **App-wide**: `MenuBar/index.module.css` (overflow menu whites), `Tree/Node.module.css`, `Tree/Project/Editing.module.css`, `LayoutProtected/Breadcrumbs/Crumb/style.css`, `FormHeader`, `FormTitle`, `EmailVerificationBanner`, `components/index.module.css` (home cards/title halo), `Initiating.module.css`
- **shared/**: `Section`, `SectionLevel2`, `SectionDescription`, `Row`, `Label`, `LanguageChooser` (popup), `FieldFormInForm`, `UploadButton`, `DesignEditorLayout`, `PuckPropsPanel`
- **Map UI chrome**: `LeftMenuDrawer` (index/Content/Resizer), `RightMenuDrawer/Info`, `BottomRightControl` (UiButton.module.css + uiButton.css), `Popup.module.css`

## 6. Out of scope
- Print/report output (stays light — desirable for printing), WMS/aerial tile layers, third-party widget internals beyond the Uploadcare `--darkmode` flag.
