# import example data

Goal: explore how this data can be best edited, presented, analyzed. Find missing features

In this ps project, similar projects like the also existing apf2 should be able to be managed.
In order to find missing features (compared to apf2) and new useful features, I want to import example date from apf2 into ps.
The import should be able to be done repeatedly (after rebuilding the backend-dev backend) via a command.

Some details for the import:

- project name: apflora
- species to import: Abies alba, Aldrovanda vesiculosa and pulsatilla vulgaris
- places level 1: Populationen
- places level 2: Teil-Populationen
- for now lets ignore Freiwilligen-Kontrollen. Use Feld-Kontrollen for Checks
- for now lets ignore observations (Beobachtungen)
- for now we do not need translations, lets use German

Please have a look at this daunting task and tell me what you need to have a go at it.
